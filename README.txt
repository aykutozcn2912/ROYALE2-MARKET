ROYALE2 MARKET V1
==================

Bu paket, royale2.shop için hazırlanmış statik V1 tasarım demosudur.

DOSYALAR
- index.html : ana sayfa
- style.css  : tasarım
- script.js  : örnek ilanlar ve filtreler

ÖNEMLİ
Bu V1 gerçek üyelik, ödeme, veritabanı veya ilan kaydetme sistemi içermez.
Bunlar ikinci aşamada Supabase ile eklenebilir.

YERELDE TEST
index.html dosyasına çift tıklayıp tarayıcıda açabilirsiniz.

ÜCRETSİZ YAYINLAMA
Önerilen altyapı: GitHub + Cloudflare Pages.
1. GitHub hesabı açın.
2. Yeni public repository oluşturun: royale2-market
3. Bu klasördeki 3 dosyayı repository'ye yükleyin.
4. Cloudflare Pages'e GitHub hesabınızı bağlayın.
5. royale2-market repository'sini seçin.
6. Framework: None / Static HTML
7. Build command boş bırakın.
8. Output directory: /
9. Deploy edin.
10. Cloudflare'de Custom Domains bölümünden royale2.shop ekleyin.
11. Hostinger DNS ekranında Cloudflare'ın verdiği DNS kayıtlarını kullanın.

Not: Domain Hostinger'da kalabilir; hosting'in Hostinger'dan alınması gerekmez.
